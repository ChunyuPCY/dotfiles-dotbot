# L4 · 工作流熟练（练成肌肉记忆）

## 目标
不做配置，专练手感。把高频操作练到"不用想就能按"。持续 2~4 周，每周集中攻 1~2 组。

## 核心方法：刻意练习
- 每次只练**一组**，重复到条件反射。
- 用"反馈自测"验证：能不能在**不看提示**的情况下完成，且不犯错。
- 犯错 → 停下 → 回忆正确按键 → 再来。肌肉记忆来自"错误被纠正"。

## 练习清单

### 1. 移动与编辑基础（第一周）
| 动作 | 按键 |
|---|---|
| 上下左右（hjkl） | `h j k l` |
| 词首/词尾/大词 | `w b e` / `W B E` |
| 行首/行尾/文件头尾 | `0 $ gg G` |
| 删除词/整行 | `dw dd D` |
| 复制/粘贴 | `yy p P` |
| 撤销/重做 | `u <C-r>` |
| 查找 | `f<char>` `F<char>` `t<char>` `; ,` |

**反馈自测**：打开一段代码，用 5 个不同动作各定位到指定字符，全程不看键盘。

### 2. 文本对象（mini.ai，第二周）
| 动作 | 按键 | 含义 |
|---|---|---|
| 改括号内 | `ci(` / `ci)` | change inside () |
| 删引号内 | `di'` `di"` | delete inside quotes |
| 选中函数体 | `vif` / `vaf` | inside/around function |
| 改下一个参数 | `cina` | change inside next arg |
| 整 buffer | `diB` | delete inside buffer |

**反馈自测**：对任意一行含括号/引号的代码，能在 3 秒内完成"改括号内文字"。

### 3. Surround + operators（第三周）
| 动作 | 按键 |
|---|---|
| 加括号 | `saiw)` `ysiw)` |
| 删除环绕 | `sd'` `ds'` |
| 替换环绕 | `srb[` `cs([` |
| 替换词 | `griw` |
| 排序选中 | `vipgs` |
| 执行 Lua 行 | `g==` |

**反馈自测**：给一个裸单词加引号、把 `()` 换成 `[]`、替换一个单词，各 5 秒内。

### 4. 文件/搜索导航（mini.pick，第四周）
| 动作 | 按键 |
|---|---|
| 找文件 | `<Space>ff` |
| 全文搜索 | `<Space>fg` |
| 找 buffer | `<Space>fb` |
| 查 help | `<Space>fh` |
| 文件浏览器 | `<Space>ed` |
| 恢复上次 picker | `<Space>fr` |

**反馈自测**：10 秒内从空白打开任意已知文件；30 秒内找到某个函数定义（`<Space>fg` 搜函数名）。

### 5. 窗口/缓冲/会话（第四周）
| 动作 | 按键 |
|---|---|
| 窗口间移动 | `<C-w>h/j/k/l` |
| 窗口拆分 | `<C-w>s/v` |
| 切 buffer | `]b` `[b` |
| 删除 buffer | `<Space>bd` |
| 会话保存/恢复 | `<Space>sn` `<Space>sr` |

## 验证反馈（量化）
本仓库的 `mini.misc` 提供了计时工具（`30_mini.lua:276`）：
```
:lua =MiniMisc.stat_summary(MiniMisc.bench_time(function() vim.cmd('normal! ci(') end, 10))
```
或自己用秒表：记录"打开文件→改一处→保存退出"总耗时，每周对比。

## 网络大神总结

> **ThePrimeagen**：他最有名的主张之一是"**Vim 是一门语言**"——`d`(动词) `i`(介词) `w`(对象) 组合成句子。所以不要背按键，要背**语法**：动词 + 介词 + 文本对象。掌握了语法，几千个"快捷键"其实只是几十个词根的组合。

> **Chris Patti / 多数效率博主共识**：学习 Vim 最高效的方式是"**用起来 + 少量刻意练习**"，而不是一次看完教程。每天用，遇到重复动作就停下来问"有没有更快的键"，去查 `:h`，再用。这种"需求驱动"的学法学得最牢。

> **TJ DeVries**：他建议"**拥抱摩擦**"——刚开始用 picker/textobject 会比你原来的方式慢，这是必经阶段。坚持两周，速度会反超，因为你省的每一次"找鼠标/翻菜单"都在积累。
